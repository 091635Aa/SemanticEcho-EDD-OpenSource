# 情感导演解码（Emotional Director Decoding, EDD）

> **一句话介绍**：这是一套**零权重万能插件**——不训练、不改模型权重、不做任何定制，只在解码期给模型"安排一位情感导演"，就能让 **Qwen2.5-1.5B** 在 7 模式全流程评测中登顶第一（综合 0.7046），对真人 LLM-Judge 胜率 **+122%**，且在 3 个不同架构/规模模型上一致正向（泛化 **+67%~+233%**）。

---

## 🍼 小白先看这里（3 分钟看懂）

**1. 什么叫"零权重万能插件"？**

模型生成回答时是一个词一个词"抽签"选出来的。**解码期**就是它抽签的窗口。EDD 在窗口外装了一位"情感导演"：
- 先**感知**用户情绪（VAD 三维情感状态）和任务类型（角色扮演 / 情感倾诉 / 知识决策 / 格式任务）；
- 再在**采样那一刻**指挥概率走向：该共情时共情、该克制时克制、该像人时像人；
- 全程**不碰模型权重**，随时可插拔——任何对话模型装上即用。

**2. 为什么能"以小博大"？**

"像不像真人"和"懂不懂知识"是两件事。大模型知识多但默认带客服腔；1.5B 小模型只要把"说话方式"调对，盲评裁判（另一个 AI）就分不出来。EDD 做的正是"说话方式"这一层：压 AI 腔、保人味、稳角色、跟情绪。

**3. 它解决什么具体问题？**

- **AI 味**：三通道抑制"作为AI/总之/很高兴为您服务"式套话；
- **身份暴露**：全文任意位置出现"我是AI"→ 持续拦截至句界；
- **角色漂移**：角色扮演时按角色基调锚定，用户开心/难过都不跳戏；
- **情绪跟丢**：对话进入长上下文后情绪衰减，EDD 在解码期持续把情绪"导演"回来。

## 🧭 架构（三导演层 + 五正交通道）

**三层导演机制**

| 机制 | 缩写 | 作用 |
|---|---|---|
| 任务自适应强度 | TAD | 探测任务类型并分配强度：角色扮演 1.25 / 情感倾诉 0.9 / 知识决策 0.55 / 格式任务 0.2 |
| 进度感知强度调度 | PIS | 开头强（立情感基调）→ 中段稳 → 尾段 0.55 渐弱自然收尾 |
| 在线质量纠正 | OQC | AI 腔三通道抑制 + 情感缺失检测 + 角色漂移拉回 + 正性模板劫持抑制 |

**五条正交通道**

1. **DMR 稠密乘性重加权**：`p'(w) ∝ p(w)^(1-α) · q_emo(w)^α`，概率空间直达情绪方向；
2. **KV 情感调制**：注意力缓存空间对情感 token 的 K/V 加权（含 V 调制）；
3. **锚点 tanh 加性偏置**：表示空间向"情感锚点"（温柔/开心/难过/愤怒/害怕/平静）温和加偏；
4. **AI 腔三通道抑制**：首 token 黑名单 + decode 级 top-300 过滤 + 短语感知；
5. **DSA 动态方向**：融合 hidden state 的动态方向与静态目标方向，避免注入僵化。

**角色感知锚定**（v6.5+）：`v_target = 0.7·v_角色 + 0.3·v_用户`；低唤起角色（前辈/老师/兄长/毒舌/老人）遇用户开心时抑制"太好了！"式热情模板劫持，高唤起角色（同桌/小女儿）保留自然同乐。
